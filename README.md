# Fantasy Go World 围棋对弈平台

基于 Go + React 的现代化在线围棋对弈系统。支持完整的落子校验、提子、死活结算及长生命周期 WebSocket 实时对战。

## 📚 详细文档与工程规范

本项目摒弃了“边想边写”的传统开发模式，而采用了非常严谨的**规格驱动开发 (Spec-Driven Development)**。从宏观架构分层、WebSocket 并发模型设计，到微观的业务状态流转与单测验收，均已沉淀了极高质量的领域文档。

为了防止文件散落造成信息不同步，我们将所有的指引收口到了以下两个最核心的骨干文件中：

### 1. 规章制度与目录结构
- **📜 [项目工程规范 (Specification)](docs/spec/specification.md)**
  这里详细规定了前端与后端的代码规约、测试门禁如何卡点执行、文档结构的摆放规则（项目物理结构的说明），以及非常关键的 Git Commit 原子化提交流程。

### 2. 全景技术架构索引
- **🤖 [全景索引与决策树 (AGENTS.md)](AGENTS.md)**
  这是本项目的“藏宝图”（The Single Source of Truth）。它内部编织了所有 REST API 定义（Swagger）、高并发 WebSocket 详细架构、数据库结构变迁原理、Go 引擎的并查集打劫算法等海量文档的聚合链接。
